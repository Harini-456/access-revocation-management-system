# Access Revocation Management System

The **Access Revocation Management System** is a full-stack web application developed to securely manage employee access permissions within an organization. The system enables administrators to grant or revoke employee access and allows employees to submit access requests when access is revoked.

---

##  Features

- Employee Signup and Login
- JWT Authentication
- Role-Based Access Control
- Grant/Revoke Employee Access
- Access Request Management
- Approve/Reject Requests
- Access History Tracking

###  Employee
- Signup/Login
- Submit access requests
- View access status

---

##  System Workflow

1. Employee registers and logs into the system.
2. Admin grants or revokes access permissions.
3. Employees can submit requests for revoked access.
4. Admin reviews and approves/rejects requests.
5. System maintains access history for tracking.
